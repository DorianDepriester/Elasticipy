Elasticipy Example Gallery
==========================

Welcome to the **Elasticipy** example gallery!
This page contains a collection of plotting capabilities of the Elasticipy package for various types of objects.

.. note::

    Interactive plots shown here use `plotly <https://plotly.com/python/>`_. When running these examples **locally**
    (e.g. from a terminal or a script), interactive figures are not displayed automatically: end the script with
    ``fig.show()`` and the figure will open in your web browser. In a **Jupyter notebook**, figures are displayed
    inline automatically, so no extra command is needed.
